# NETA-LAB-007 — Controlled Large Upload / Outbound Asymmetry

Validates cumulative outbound transfer accounting and high outbound asymmetry using a bounded generated payload. No user files are read or transmitted.

## Run

Server:
`python3 ../../common/server/tcp_lab_server.py --bind 0.0.0.0 --port 18447 --connections 1 --scenario NETA-LAB-007`

Linux client: `./linux/run.sh <LAB-IP> 18447`

Windows client: `.\windows\run.ps1 -HostAddress <LAB-IP> -Port 18447`

Default payload is 32 MiB of generated bytes. Expected evidence includes lifecycle, process, direction, endpoint, cumulative bytes sent/received and transfer fidelity. Expected finding is `HIGH_OUTBOUND_ASYMMETRY`; `LARGE_EGRESS_TRANSFER` is only appropriate if the active rule set intentionally defines it. A small-upload control must stay quiet.
