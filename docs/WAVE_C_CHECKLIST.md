# Wave C validation checklist

For each Wave C lab, record:

- ground truth;
- observed resolver/TLS/network evidence;
- evidence fidelity and provenance;
- expected assurance vs actual assurance;
- expected findings vs actual findings;
- forbidden/unexpected findings;
- capability gaps;
- false-positive controls;
- overall PASS / PASS_WITH_CAPABILITY_GAP / failure reason.

Do not use scenario IDs, lab-only output markers, or generated certificate filenames as detection inputs.
